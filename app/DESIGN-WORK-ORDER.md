# KYCode Studio — Design & Product Work Order

Status: decision-complete. Scope: `app/` only (`app/server.py`, `app/static/index.html`, `app/static/app.js`, `app/static/style.css`, `app/README.md`). Every standard below is cited to an inspected primary source or a repo path in §7; no uncited metric is a gate.

## 1) Decision on stack

**Recommendation: middle path — framework-agnostic tokens + components now, React lift later only by re-decision.** Keep zero-install Python-stdlib serving vanilla HTML/CSS/JS. Freeze the design contract as DTCG JSON → generated `tokens.css` + `components.css`, with component APIs mirroring shadcn/Base props (`variant`/`size`/density/state via `data-*`, surface/foreground token pairs). A later React move is then a re-skin, not a redesign.

Decision criteria (literal React + Tailwind v4 + shadcn(Base) + ReUI wins **only if all** hold):
1. "Zero-install" is explicitly redefined as zero-install for the end user (prebuilt static bundle served by stdlib; Node/license only in dev/CI).
2. Team accepts React lock-in + ReUI license cost (`REUI_LICENSE_KEY`, registry-only `https://reui.io/r/{style}/{name}.json`, no npm package).
3. Roadmap needs complex a11y widgets within 6 months (Combobox, Dialog, Menu, DataGrid, Command, DatePicker) whose focus-trap/roving/ARIA logic Base/Radix provide free.
4. Hiring/AI-tooling velocity (registry, MCP, llms.txt) outweighs bundle/toolchain cost.

Faithful vanilla wins if zero-Node-anywhere is a product guarantee, the surface stays ~15 mostly-static components, and offline/single-file matters — then hand-audited ARIA per Radix patterns is non-negotiable for every interactive widget. **Rejected:** copying oklch values without semantic pairs, radius scale, density, dark audit, or state tokens (visual mimicry, not a design system).

**Tier split (critic-mandated, resolves all conflicts):** *Local Studio* = localhost default: no charges without `STRIPE_SECRET_KEY`, Demo labels, no webhooks, no public RSS claims. *Hosted Publish* = publicly addressable deploy: Stripe webhooks/entitlements, public RSS, discovery. No feature may be specified without naming its tier.

## 2) Design standards adopted (each cited)

- **Tokens:** 3-layer contract — primitives (oklch palettes) → semantic vars (`--background`/`--primary`/`--sidebar-*` etc., single `--radius: 0.625rem` deriving sm–4xl) → `@theme inline` mapping; no raw hex in components. Add ReUI semantics first-class: `--info/--success/--warning/--invert/--destructive-foreground` + foregrounds, light+dark, for quiz/proof/revenue/destructive states. Tailwind v4 CSS-first `@theme` namespaces (`--color-* --font-* --text-* --spacing-* --radius-* --breakpoint-* --container-* --animate-*`) defined even when hand-rolled. Source of truth: DTCG Format 2025.10 JSON (`$value`/`$type`, `{alias}` refs) generating CSS vars — pinned to 2025.10, never described as a W3C Recommendation. Dark: `@custom-variant dark(&:is(.dark *))`, tri-state system/light/dark with anti-FOUC head script (`localStorage` > `prefers-color-scheme`), `color-scheme`, dark tokens audited separately.
- **Components/shell:** composable Sidebar (Provider/Header/Content/Footer/Inset; `sidebar|floating|inset`; collapsible `offcanvas|icon|none`; `--sidebar-width` vars; keyboard/cookie state) specified behaviourally. Density as API: two densities via `--density-*` + Frame `spacing sm|default|lg`, `dense`, `--frame-radius` concentric calc. Inventory beyond Frame/Badge/Alert: shell + forms + overlays + data + Code/FileTree/Chat/Message/Empty/Skeleton/Toast/Command.
- **A11y floor: WCAG 2.2 AA** (incl. 2.4.11 Focus Not Obscured, 2.5.7 Dragging, 2.5.8 Target Size, 3.2.6 Consistent Help). Text ≥4.5:1 (≥3:1 large: 18pt / 14pt bold); non-text ≥3:1, no rounding 2.999:1; targets ≥24×24 CSS px floor, ≥44×44 px app rule for primary controls; `:focus-visible` ≥2 px perimeter, ≥3:1 focused-vs-unfocused (2.4.13 AAA adopted as gate); `scroll-padding` = sticky header/player height + 8 px. APCA advisory only — WCAG 3 is an exploratory draft; never pass a pair failing 4.5:1 on APCA. oklch ramps step L only, gamut-checked, final ratios still verified in sRGB.
- **Perf/motion:** CWV at p75, mobile+desktop separately, throttled (Moto-class 4× CPU + Slow 4G): LCP ≤2.5 s, INP ≤200 ms, CLS ≤0.1 (app gate ≤0.05, space reserved for art/waveforms/sidebar); ≤100 KB gzip initial CSS+JS, no render-blocking webfont; long tasks chunked <50 ms, paint pressed/correct before awaiting fetch/eval. View Transitions feature-detected (`document.startViewTransition`), 150–250 ms opacity/transform only, unique names, passing fallback — never a gate (not Baseline Widely Available). `prefers-reduced-motion`: crossfade ≤100 ms or instant; state never by motion alone. Container queries (`container-type: inline-size`, gates ~20em/30em/45em) over viewport queries; `:has()` for state styling only, ARIA/JS source of truth.
- **Audio/RSS:** MediaRecorder MIME ladder via `isTypeSupported()`, `audioBitsPerSecond`, `start(timeslice)` incremental persistence; explicit `getUserMedia` constraints + device picker + per-`DOMException` recovery; Chrome SpeechRecognition is server-based/offline-incapable — disclose before first mic use, typing is a full peer; AnalyserNode real waveform/peaks; Media Session metadata + handlers behind `'mediaSession' in navigator`. RSS: RSS 2.0 + iTunes/content namespaces, enclosure URL+length+type, immutable GUID, RFC 2822 `pubDate`, required show cover, HEAD + byte-range. One WebVTT reused as `<track>` captions + `podcast:transcript` + search text; `podcast:chapters` JSON from code-path hops. Loudness (−14 dB LUFS / <−1 dBTP, Spotify *Artists* page) is **advisory report only** — podcast-specific target unverified, stdlib cannot measure LUFS.
- **Trust/money (Hosted tier):** webhook-driven idempotent fulfillment (`checkout.session.completed` + invoice/subscription/refund/dispute); Connect hosted onboarding (Account Links) gated on `charges_enabled`/`payouts_enabled`; subscription states `incomplete/trialing/active/past_due/canceled`; customer portal; gross/fee/net + paid/available/paid-out ledger (first payout typically 7–14 days). OG per episode: `og:title/type/image/url` required + description/`og:audio`.

## 3) Ordered work phases (exact surfaces/files)

**P0a — Unforgeable proof + security (before any visual work).** `app/server.py` (esp. `row_to_episode` at `:360`, `POST /api/episodes`, `create_checkout`/`verify_checkout`): require server scan/trace session ID; bind badge to repo commit + `file:line` snippet hashes + server-graded quiz attempt + timestamp; "what this badge does not prove" disclosure; Demo labeling everywhere; never badge narration-only as recorded. Add threat model: bind address, auth, CSP, path-traversal, prompt-injection from repo content; session-only API-key handling with explicit consent (remove plaintext `localStorage` apiKey). Tier: both.

**P0b — Semantics, states, delivery fixes.** `app/static/index.html`, `app.js`, `style.css`, `server.py`: `<main>` + skip link + landmarks; `show()` moves focus, sets `document.title`/`aria-current`; native links/buttons (kill `<article onclick>`); labelled fields (no placeholder-as-label, `autocomplete`/`inputmode`/`describedby`/invalid states); full state matrix (default/hover/active/focus-visible/disabled/loading/error/success) + skeletons + toasts + double-submit disable; transcript `role=log` + `aria-live`; draft autosave/restore; real History API + `popstate` + focus restoration. Server: Range/206 + HEAD, correct recorder MIME (Safari mp4 vs forced `.webm`), `Cache-Control`/ETag + hashed/immutable statics, CSP/`nosniff`/`Referrer-Policy`, `defer`/module scripts.

**P0c — Token system.** New DTCG JSON source → generated `tokens.css` (§2 full semantic set incl. ReUI 9 tokens, brand hue, spacing/type/motion/elevation/z scales, tabular-nums for stats/money, fluid type fixing h1 1.375rem/h2≈body) in `app/static/`; `@layer base/components/utilities`; kill inline `style=` attributes; `Intl` date/currency formatting (no raw ISO in Revenue).

**P1a — Shell + components.** `index.html`/`style.css`/`app.js`: job-based sidebar (Talk/Quiz/Record/Publish/Earn), repo as top-left workspace switcher, episode as fundamental unit (Draft→Review→Published + triage/review inbox); container-query Frame/cards/player/quiz; bottom-nav/drawer <1024 px; sticky multiline autogrow composer; Cmd-K as *inspiration-level* navigation (no sub-100ms/crash-free gate — marketing claims, see §5).

**P1b — Audio core.** `app.js:62-79,149-168,305-307`, `server.py:641-659`: recorder (MIME ladder, timeslice chunks, mic-check/device picker, timer/levels/clipping meter, pause/preview/retake); custom player (waveform from persisted peaks, chapters from hops, ±10–30 s seek, speed, transcript-sync highlight, Media Session, keyboard shortcuts, no-drag alternative); TTS voice/rate/stop controls, labelled synthetic narration; WebVTT + chapters JSON generation; loudness advisory report stored in proof.

**P1c — Publish/SEO/RSS.** `server.py`: per-episode SSR head (`/e/<id>`, `/c/<handle>` — canonical, OG/Twitter, `theme-color`, favicon, manifest, PodcastEpisode JSON-LD, generated proof-card image); valid podcast RSS (§2) + built-in feed checker as publish gate; restyle `/embed/<id>` on same tokens (dark + responsive). Tier: public claims Hosted only.

**P2 — Hosted monetization + discovery.** `server.py` + `app.js` (`openEpisode`/`loadRevenue`/`checkStripeReturn`): webhooks + idempotent fulfill; Connect Account Links + capability gating; server-side entitlement paywall (free preview vs full trace/transcript); ledger states pending/available/paid/refunded/disputed, net after 10% + Stripe fees; customer portal; private/tokenized RSS only where platform rules allow (never claimed for Apple). Discovery IA: artwork system, duration/date/proof facets, sortable/filterable grids, creator analytics (trends/date-range/export) replacing admin tables and substring-only search. Clips/cross-promo/comments only with real-only social proof (verified traces, Stripe-confirmed supporters; empty states never fake counts).

## 4) Acceptance gates (failure signal named)

| Phase | Gate | Failure signal |
|---|---|---|
| P0a | Forged client `code_path`/`quiz` payload without server session is rejected; badge shows commit + hashes + disclosure | `POST /api/episodes` returns `verified` for a client-only payload |
| P0b/P0c | axe-core 0 violations + manual keyboard-only pass (chat/quiz/record/publish/checkout); Playwright bounding-box audit at 320 px (nothing <24 px, primary ≥44 px); Tab walk at 200%/400% with 100% of focused element visible; CI token-pair contrast 4.5:1/3:1 in sRGB, light+dark | Any axe violation, obscured focus, sub-24 px target, or failing pair blocks release |
| P0b | Range request returns `206` + correct MIME; Back button restores view + focus; reload restores draft | Full-body `200` on Range, broken Back, or lost draft |
| P1a | Screenshot diffs at 360/768/1280 px, light+dark, both densities; container breakpoints 20/30/45em verified in sidebar/main/embed placements | Unreviewed visual diff or viewport-query regression |
| P1a/P1b | Lighthouse throttled mobile: LCP ≤2.5 s, CLS ≤0.05; PerformanceObserver `longtask`+`event-timing` scripted quiz+record loop: INP ≤200 ms, no task ≥50 ms blocking feedback; initial CSS+JS ≤100 KB gzip | Any budget exceeded on the throttled run (raw localhost numbers do not count) |
| P1b | Crash/close mid-record recovers persisted chunks; each `getUserMedia` error shows its specific recovery; SR smoke (VoiceOver/NVDA) on quiz/record/publish live regions; reduced-motion emulation passes every animated view | Lost episode, generic mic error, silent live region, or motion-only state |
| P1c | Feed checker validates namespaces/enclosure length/GUID/RFC 2822 dates/show cover before Publish; `/e/<id>` head differs per episode with full OG set | Publish succeeds with an invalid feed or identical static head |
| P2 | Webhook replay is idempotent (double-delivery = single entitlement); paywalled episode serves no full audio/transcript pre-entitlement; ledger reconciles gross/fee/net per sale | Duplicate grant, leaked paid bytes, or gross shown as bank money |

Test commands: extend the existing suite — `python3 -m unittest discover -s tests` already runs `tests/test_studio.py` in CI (failure signal: non-zero exit); add cases there for proof forgery, Range/HEAD, RSS validity, and webhook idempotency. Add a Playwright suite (`npx playwright test` in dev/CI only — never an end-user install step) covering axe, bounding boxes, Tab visibility, reduced-motion, 320 px/200%/400%. Keep `python3 scripts/release_check.py --history` green (failure signal: non-zero exit).

## 5) Non-goals

Literal React/Tailwind/ReUI adoption as default; cloud/agent queues, tasks continuing after laptop closes, transcript delete-text-equals-delete-audio editing, 4K/Magic Clips, instant preview URLs (benchmark marketing — Linear/Raycast/Cursor/Vercel/Codex/Descript/Riverside patterns are named *inspiration only*, never acceptance criteria); "private/local voice" claims; private RSS on Apple; APCA as a pass gate; View Transitions as a gate; blocking loudness gate; any discovery/monetization scale before the P0a security/hosting gate.
