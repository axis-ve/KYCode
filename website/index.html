Know Your Code is a set of skills for working on a project you want to understand. It runs in Codex, Cursor, and Claude Code.

Ask a question, trace a bug, or make a change. It inspects your actual code, explains what it finds, and helps you check the result.

You set the pace. Ask for the short version, follow a tangent, or get straight to the fix.

LESS TYPING. MORE TALKING IT THROUGH.

Say the messy version.

We recommend trying it with voice. Talk through what you're building, ask the follow-up, and say “hang on” when something doesn't click.

“Walk me through this bit. Why did we build it this way?”

After installing, start voice in your app if it's available.

YOUR PROJECT IS THE STARTING POINT.

Bring the question.
We'll follow the code.

The skills help your coding assistant inspect your project, explain what it finds, and work out the next step with you.

Ask it to make a change and it'll check the result, then walk you through what moved.

NO PERFECT PROMPT REQUIRED.

Start where you're stuck.

Try any of these after invoking know-your-code:

  • “What happens when I press Save?”
  • “My changes disappear on refresh. Why?”
  • “Help me add a confirmation before delete.”

Ask for the short version any time. You're setting the pace.
